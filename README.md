# Casos de Automação

Portfólio de automação e IA aplicada a operações: CRM que se preenche sozinho a partir do WhatsApp, painel financeiro para leigos, painel da diretoria, painel de atendimento e campanhas, monitor das automações e lista de reengajamento.

Feito com n8n, JavaScript, APIs REST, webhooks e IA generativa como parceira de desenvolvimento.

**Todas as empresas, pessoas e números são fictícios.**

Abra `index.html` ou o site publicado pelo GitHub Pages.
